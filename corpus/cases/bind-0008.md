# E2EE vs. Art. 33/34 breach notification

The operator must assess and report a breach of data it was built not to read. Art. 33(3)(a) asks for categories and record counts only where possible, and Art. 34(3)(a) waives data-subject notice where encryption left the data unintelligible, so the law may accept an operator that can't know.

- mandating: GDPR Art. 33(1), 33(3)(a); Art. 34(1), 34(3)(a) (https://eur-lex.europa.eu/legal-content/EN/TXT/?uri=CELEX:32016R0679)

## Inclusion
No. Art. 33(3)(a) asks for categories and record counts only where possible, and Art. 34(3)(a) waives data-subject notice where encryption left the data unintelligible. An operator that can't read the data complies by reporting what it can see. Kept as a boundary case: the conflict returns only if a regulator demands detail the architecture never had.
