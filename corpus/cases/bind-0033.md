# India IT Rules 4(2) first-originator traceability vs. E2EE messaging

Messaging intermediaries must identify who first sent a given message without seeing message content and without disclosing other users' data.

## Instruments
- mandating: IT Rules 2021 Rule 4(2), second proviso (https://www.meity.gov.in/static/uploads/2024/02/Information-Technology-Intermediary-Guidelines-and-Digital-Media-Ethics-Code-Rules-2021-updated-06.04.2023-.pdf)

## Analysis
In E2EE the server sees ciphertext. To answer "who first sent this plaintext" it must have recorded, for every message from every user, a content fingerprint linked to a sender, before any order exists. That registry is the population-wide data the proviso says need not be disclosed. It also fails on its own terms: a one-byte edit or a re-encode produces a new hash and a new "first originator". The proviso deeming an out-of-India originator to be the first in-India sharer adds a per-forward jurisdiction lookup.

## Inclusion
Traceability after the fact needs a per-message record made before the order. Making that record for all users is the bulk disclosure surface the rule disclaims and breaks the E2EE property that the server can't link content to senders. No engineering budget avoids collecting it.
