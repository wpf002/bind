# Traffic-data retention against no-logs anonymity networks

Retention measures require communications providers to keep traffic and subscriber data; anonymity networks are built so that no single operator ever learns the association being retained.

## Instruments
- mandating: Data retention National measures (https://curia.europa.eu/juris/liste.jsf?num=C-293/12)

## Analysis
In a multi-hop network the entry node knows the user but not the destination and the exit knows the destination but not the user. The record the retention duty describes exists nowhere. Producing it requires an operator to correlate across hops, which is precisely the attack the routing design defends against.

## Inclusion
The datum being demanded is not stored anywhere because the system is engineered so no participant can derive it. Compliance means re-architecting into the attack.
