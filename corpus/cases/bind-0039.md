# China game real-name registration vs. threshold-only age proof

China requires every online game user, adult or minor, to register and log in with real identity information checked through the NPPA verification system. A threshold-only age proof tells the operator one fact: whether the user is over 18.

## Instruments
- mandating: NPPA Notice 2021 Items 1, 2 (https://www.gov.cn/zhengce/zhengceku/2021-09/01/content_5634661.htm)
- mandating: Order 766 Art. 46(1) (https://www.gov.cn/zhengce/content/202310/content_6911288.htm)
- conflicting: PIPL Art. 6 (http://www.npc.gov.cn/npc/c2/c30834/202108/t20210820_313088.html)

## Analysis
The rule being enforced needs one bit per user. Minors may play 20:00 to 21:00 on Fridays, weekends and public holidays, and the notice sets no limit for adults. Item 2 of the 2021 NPPA notice fixes the method: every game connects to the NPPA real-name verification system, every user registers with "真实有效身份信息" (real and valid identity information), and guest mode is banned. Order 766 Art. 46 repeats the verification duty in a State Council regulation. So an adult who only needs to show adulthood must still register a real identity. An anonymous age credential isn't identity information, and the operator can't serve a user on it. PIPL Art. 6 limits collection to the minimum scope the purpose needs. Art. 13(1)(3) allows processing needed to meet a statutory obligation, so the real-name rule prevails. EU guidance accepts double-blind age tokens for age checks. This mandate names identity as the input, so that route is closed.

## Inclusion
No. A threshold-only proof would be enough to apply the time limits, but item 2 requires real identity registration through the NPPA system and bans service to anyone without it. An operator can't comply and also learn only one bit. Spending doesn't change what the notice names as the input. The national network ID hides the plaintext ID from the platform and still hands it an identifier tied to one person.
