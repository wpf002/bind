# Rectification of inaccurate data in a consensus-finalised state

GDPR Art. 16 requires correction of inaccurate personal data; finalised ledger state is by construction the only state the network will accept.

## Instruments
- mandating: GDPR Art. 16 (https://eur-lex.europa.eu/eli/reg/2016/679/oj)

## Analysis
Rectification differs from erasure in a way that matters: the controller must make the record accurate, not absent. Appending a correction leaves both versions authoritative to different readers, which is what the accuracy duty exists to prevent. There is no mechanism by which the earlier entry stops being a valid reading of the record.

## Inclusion
Appending a correction is the only available action and does not satisfy the duty, because the inaccurate entry remains canonical for any party reading at that height.
