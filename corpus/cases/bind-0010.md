# National interception root installed in subscriber trust stores

A national measure requires operators to route traffic through a state-issued root installed on devices; TLS authentication assumes no admitted root can impersonate an unrelated domain.

## Instruments
- mandating: KZ root mandate Art. 26-1 (https://adilet.zan.kz/rus/docs/Z040000567_)

## Analysis
Any trusted root can issue for any name. A mandated interception root therefore holds impersonation capability over every site, which is the capability the trust model exists to deny. Browser vendors responded by hard-blocking the certificate, which is a refusal rather than a resolution.

## Inclusion
There is no construction under which a root can decrypt arbitrary sessions and simultaneously be unable to impersonate arbitrary sites. The capability is the same capability.
